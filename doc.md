# dthusian's Matcha Flavoured Fork

Since this datapack is a derivative of Klei's Matcha Flavoured datapack, most of this documentation applies to both versions. Any changes specific to dthusian's fork will be labelled as such.

## General Changes

- (Klei-specific) The day is 3x longer, now 72000 ticks (60 minutes) instead of 24000 (20 minutes).
- All villages now spawn as abandoned villages with no villagers present.

## Cosmetic Changes

- (Klei-specific) Villages play creepy sounds wnen the player is inside of them.

## Hostile Mobs

- Zombies now move faster.
- Skeletons now have 10 health (5 hearts)
