# dthusian's Matcha Flavoured Fork Guide

Since this datapack is a derivative of Klei's Matcha Flavoured datapack, most of this documentation applies to both versions. Any changes specific to dthusian's fork will be labelled (dthusian) and changes specific to the official Klei's Matcha Flavoure will be labelled (Klei).

## General Changes

- (Klei) The day is 3x longer, now 72000 ticks (60 minutes) instead of 24000 (20 minutes).
- All villages now spawn as abandoned villages with no villagers present.
  - (Klei) Villages play creepy sounds wnen the player is inside of them.
